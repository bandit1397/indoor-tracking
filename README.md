# 지하철 실내 길찾기 (Subway Indoor Navi)

외국인 방문객이 지하철역 안에서 길을 잃지 않도록 돕는 **무료·API 없는** 실내 내비게이션입니다.

1. 관리자가 역 안을 휴대폰 동영상으로 걸으며 촬영합니다.
2. AI가 영상에서 지점을 뽑고, **겹치는 장면을 자동으로 찾아** 역 전체 길 지도를 만듭니다.
3. 사용자가 주변(표지판, 출구 번호 등)을 사진으로 찍으면 현재 위치를 찾습니다.
4. 목적지를 고르면 최단 경로를 **사진 단계별로** 안내합니다 (한국어/English/中文/日本語).

모든 AI 계산은 PC와 사용자 휴대폰 브라우저 안에서 실행됩니다. 서버, 유료 API, 앱 설치가 필요 없습니다.

- 사이트: https://bandit1397.github.io/indoor-tracking/

```
mapper/            PC에서 실행하는 지도 만들기 (Python)
  export_model.py    무료 AI 모델(MobileNetV3) → web/model/embed.onnx (최초 1회)
  build_map.py       동영상 → web/data/<역>/graph.json + 사진
stations/seoul/    서울역 원본 자료
  videos/            촬영한 동영상을 여기에 넣기 (git에는 안 올라감)
  labels.csv         목적지 이름표
web/               휴대폰용 길찾기 웹페이지 (GitHub Pages로 배포)
```

# 서울역 지도 만들기: 촬영부터 사이트 반영까지

`web/data/seoul/graph.json`은 **직접 작성하는 파일이 아닙니다.** 동영상을 넣고 명령어 하나를 실행하면 자동으로 만들어집니다.

| 단계 | 할 일 | 걸리는 곳 |
|---|---|---|
| 1 | 서울역에서 동영상 촬영 | 서울역 |
| 2 | 영상을 PC 폴더로 옮기기 | PC |
| 3 | 목적지 이름 적기 (`labels.csv`) | PC, 메모장 |
| 4 | 지도 만들기 → `graph.json` 자동 생성 | PC, PowerShell |
| 5 | 인터넷 사이트에 올리기 | PC, PowerShell |
| 6 | 휴대폰으로 시험하기 | 서울역 |

> 처음에는 **영상 2~3개**로 작게 시험해 보세요. 예: 1호선 승강장 → 1번 출구, 그 중간에서 4호선 쪽으로 갈라지는 길.

## 1단계: 서울역에서 촬영하기

### 1-1. 언제 찍을까요? (시간대)

AI는 벽, 천장, 표지판처럼 **움직이지 않는 것**을 기준으로 위치를 찾습니다. 그래서 사람이 적을수록 좋지만, **실제 이용할 때와 역 모습이 같아야** 합니다.

| 시간대 | 장점 | 주의할 점 | 추천 |
|---|---|---|---|
| 평일 오전 10시~오후 4시 | 사람이 적고, 실제 이용할 때와 모습이 같음 (상점 열림, 조명 정상) | 사람이 조금 있음 | ⭐ **가장 추천** |
| 첫차 직후 (평일 오전 5시 30분~7시) | 사람이 거의 없음 | 상점 셔터가 내려져 있어 낮과 모습이 다름 | 보조로만 |
| 출퇴근 시간, 주말 오후 | 없음 | 사람이 표지판을 가림 | ✗ 피하기 |

- 상점 셔터, 광고판처럼 시간에 따라 모습이 바뀌는 곳은 위치를 헷갈리기 쉽습니다.
- 출구 번호판, 노선 안내판, 기둥, 계단처럼 **항상 그대로인 것**은 몇 시에 찍어도 괜찮습니다.
- **나중에 같은 경로를 다른 시간(사람이 조금 있는 시간)에 한 번 더 찍어 추가하면** 지도에 두 가지 모습이 다 들어가서 더 튼튼해집니다.

### 1-2. 사람이 있어도 되나요?

네, 몇 명 지나가는 정도는 괜찮습니다. 다만:

- 사람이 표지판이나 출구 번호를 가리면 그 장면은 위치 찾기에 쓸모가 줄어듭니다. **사람이 지나갈 때는 잠깐 기다렸다가** 표지판이 보일 때 찍으세요.
- 사람으로 가득 찬 장면은 영상끼리 겹치는 곳을 찾을 때 잘 연결되지 않을 수 있습니다.
- 특정인을 따라가거나 가까이에서 찍지 마세요.

### 1-3. 개인정보 (얼굴)

원본 영상은 GitHub에 올라가지 않지만, **영상에서 뽑은 사진은 사이트에 공개됩니다.**

- 4단계에서 얼굴이 자동으로 흐리게 처리됩니다.
- 단, 현재 방식은 **정면 얼굴**만 잘 찾습니다. 옆얼굴, 고개 숙인 얼굴, 멀리 있는 작은 얼굴은 놓칠 수 있습니다.
- 그래서 **5단계(올리기) 전에 `web\data\seoul\frames\` 폴더의 사진을 한 번 훑어보세요.** 얼굴이 잘 보이는 사진이 있으면 그 구간을 다시 찍거나 알려 주세요.

### 1-4. 역 촬영 규칙

- 개인이 휴대폰으로 걸으며 찍는 것은 보통 문제가 되지 않습니다. 단, **삼각대를 세우거나 통행을 막으면 안 됩니다.**
- 나중에 **공개 서비스로 운영**하려면 역 운영사의 허가를 받는 것이 안전합니다. 서울역은 구역마다 운영사가 다릅니다.

  | 구역 | 운영사 |
  |---|---|
  | 1·4호선 | 서울교통공사 |
  | 공항철도 | 공항철도㈜ |
  | KTX, 경의중앙선 | 코레일 |

- 정확한 법적 기준이 필요하면 운영사나 전문가에게 확인하세요.

### 1-5. 경로 나누기

- 경로마다 동영상 1개씩 찍습니다.
  - 예: 영상 1 = 1호선 승강장 → 1번 출구
  - 예: 영상 2 = 영상 1의 중간 지점(환승통로) → 4호선 승강장
- **가장 중요:** 영상끼리 겹치는 구간이 있어야 자동으로 이어집니다. 영상 2는 영상 1이 지나간 장소에서 시작하세요.
  ```
  영상 1:  1호선 승강장 ──────●────────── 1번 출구
                              │ (겹치는 곳: 환승통로)
  영상 2:                     ●────────── 4호선 승강장
  ```
- 가능하면 같은 길을 반대 방향으로도 찍습니다. 돌아보는 방향의 풍경이 다르기 때문입니다.

### 1-6. 찍는 방법

- **가로 또는 세로 중 하나로 정해서** 모든 영상을 같은 방향으로 찍습니다.
- 천천히 걷고, 휴대폰은 가슴 높이에서 정면을 향하게 듭니다. 흔들린 장면은 자동으로 버려집니다.
- 갈림길, 개찰구, 계단 앞에서는 2~3초 멈추고 주변을 천천히 한 바퀴 찍습니다.
- 표지판, 출구 번호판, 노선 색 안내가 잘 보이게 찍습니다. 위치 정확도가 크게 올라갑니다.
- **천장 쪽 표지판도 꼭 담아 주세요.** 붐빌 때 사용자는 사람들 머리 위의 표지판을 찍게 되므로, 지도에도 그 모습이 있어야 잘 찾습니다.
- 목적지(출구, 승강장)에 도착하면 표지판을 3초 정도 찍어 둡니다.
- 찍으면서 **목적지에 도착한 시각**(예: 1분 35초)을 메모해 두면 3단계가 쉬워집니다.

### 1-7. 촬영 전 체크리스트

- [ ] 평일 오전 10시~오후 4시인가요?
- [ ] 휴대폰 배터리와 저장 공간이 충분한가요? (1분에 약 100~200MB)
- [ ] 경로별로 출발지와 도착지를 정했나요?
- [ ] 영상끼리 겹치는 구간을 정했나요?
- [ ] 목적지 도착 시각을 메모할 준비가 되었나요?

### 1-8. 사람 없는 영상으로 만든 지도인데, 붐빌 때도 잘 찾을까요?

**대체로 됩니다. 다만 붐빌수록 약해집니다.** 실제 서울역의 붐비는 시간에는 아직 시험해 보지 않았습니다.

- **잘 되는 이유:** 표지판은 보통 사람 머리 위에 있어서 붐벼도 잘 보입니다. 또 앱이 바로 확정하지 않고 "같은 장소인가요?"라고 물어보고, 아니면 다른 후보를 보여 줍니다.
- **약한 부분:** 지금 방식은 사진 **전체**를 비교합니다. 사진의 절반 이상이 사람으로 가려지면 비슷한 장면을 못 찾을 수 있습니다.
- **보완 방법:**
  1. 위 1-1처럼 다른 시간에 같은 경로를 한 번 더 찍어 추가합니다.
  2. 6단계에서 **붐비는 시간에 직접 현장 시험**을 하고, 잘 못 찾는 곳은 표지판이 보이게 다시 찍어 보완합니다.
  3. (예정) 사용자 사진을 여러 조각으로 나눠 비교하는 기능을 추가하면, 일부가 사람에게 가려져도 나머지로 위치를 찾을 수 있습니다.

## 2단계: 영상을 PC로 옮기기

1. 휴대폰을 USB 케이블로 PC에 연결합니다. 구글 드라이브나 삼성 Quick Share도 됩니다.
   - ⚠️ 카카오톡 "나에게 보내기"는 화질이 떨어지므로 쓰지 마세요.
2. 영상을 아래 폴더에 복사합니다.
   ```
   C:\Users\owner\Desktop\indoor tracking\stations\seoul\videos\
   ```
3. 파일 이름을 영어로 짧게 바꿉니다: `route1.mp4`, `route2.mp4` …
   - 아이폰 영상(`.mov`)도 그대로 쓸 수 있습니다.

## 3단계: 목적지 이름 적기 (`labels.csv`)

1. `C:\Users\owner\Desktop\indoor tracking\stations\seoul\labels.csv`를 오른쪽 클릭 → **연결 프로그램 → 메모장**으로 엽니다.
   - ⚠️ 엑셀로 열면 한글이 깨지니 메모장을 쓰세요.
2. 예시 줄 맨 앞의 `#`을 지우고, 실제 파일 이름과 시간(초)으로 고칩니다.
   ```csv
   video,time,ko,en,zh,ja
   route1.mp4,0,1호선 승강장,Line 1 Platform,1号线站台,1号線ホーム
   route1.mp4,95,1번 출구,Exit 1,1号出口,1番出口
   route2.mp4,70,4호선 승강장,Line 4 Platform,4号线站台,4号線ホーム
   ```
   - `time`은 영상 시작부터의 **초**입니다 (1분 35초 = 95).
   - 영어 칸만 채우고 중국어, 일본어 칸은 비워 두어도 됩니다. 비우면 영어로 표시됩니다.
   - 이름 안에 쉼표(`,`)를 넣지 마세요. 칸이 나뉘어 버립니다.
3. **저장** (Ctrl+S).

## 4단계: 지도 만들기 → `graph.json` 자동 생성

1. 시작 메뉴에서 **PowerShell**을 엽니다.
2. 아래 두 줄을 차례로 붙여 넣고 Enter를 누릅니다.
   ```powershell
   cd "C:\Users\owner\Desktop\indoor tracking"
   .\.venv\Scripts\python mapper\build_map.py --station seoul
   ```
3. 끝나면 이런 메시지가 나옵니다 (영상 길이에 따라 몇 분 걸릴 수 있습니다).
   ```
   [1/2] route1.mp4: 지점 85개
   [2/2] route2.mp4: 지점 60개
   교차점(겹치는 장면) 연결 4개
   완료: 지점 145개, 길 147개, 목적지 3개 → web\data\seoul\graph.json
   ```
   → 이제 `web\data\seoul\graph.json`과 사진 폴더 `web\data\seoul\frames\`가 생겼습니다.
4. 영상을 추가하거나 `labels.csv`를 고쳤다면 2번 명령을 다시 실행하면 됩니다. 지도는 매번 새로 만들어집니다.

**메시지별 대처**

| 메시지 | 뜻 / 할 일 |
|---|---|
| `교차점 연결 0개` 또는 `지도가 2조각으로 나뉘어 있습니다` | 영상끼리 겹치는 곳이 없음 → 두 영상을 잇는 구간을 한 번 더 찍어 `route3.mp4`로 추가하고 다시 실행 |
| `목적지 '...' 가 가장 큰 지도 조각과 연결되어 있지 않습니다` | 그 목적지로 가는 길이 끊김 → 위와 같음 |
| `labels.csv 의 영상 '...' 을 찾을 수 없음` | 파일 이름 오타 → `labels.csv`와 실제 파일 이름을 똑같이 맞추기 (대소문자, 확장자 포함) |
| `동영상이 없습니다` | 2단계 폴더 위치 확인 |
| `.venv ... 찾을 수 없습니다` | 아래 [처음 설치](#처음-설치-새-pc에서만) 먼저 실행 |

**(선택) PC에서 먼저 확인하기**

```powershell
.\.venv\Scripts\python -m http.server 8000 -d web
```
PC 브라우저에서 http://localhost:8000 을 엽니다. 끝낼 때는 PowerShell 창에서 Ctrl+C를 누릅니다.

## 5단계: 인터넷 사이트에 올리기

같은 PowerShell 창에서 실행합니다.
```powershell
git add web/data stations/seoul/labels.csv
git commit -m "서울역 지도 추가"
git push
```
- 원본 동영상은 용량이 커서 자동으로 제외되고, 지도와 사진만 올라갑니다.
- 1~2분 뒤 자동 배포가 끝납니다. 진행 상황은 https://github.com/bandit1397/indoor-tracking/actions 에서 볼 수 있습니다 (초록 체크 = 완료).

## 6단계: 휴대폰으로 시험하기

1. 휴대폰에서 https://bandit1397.github.io/indoor-tracking/ 을 엽니다.
2. **📷 사진 찍기** → 찍은 장소가 맞는지 확인 → 목적지 선택 → 안내 사진을 따라갑니다.
3. **한산한 시간과 붐비는 시간에 각각 시험**해 봅니다. 붐빌 때는 사람들 머리 위의 표지판이나 천장 쪽을 향해 찍어 보세요.
4. 위치를 자주 틀리게 찾는 곳이 있으면, 그 주변을 표지판이 보이게 다시 찍어 영상을 추가하고 4~5단계를 반복합니다.

## 한계와 다음 단계

- 위치는 cm 단위가 아니라 "개찰구 앞" 같은 **지점 단위**입니다.
- 흰 벽, 타일만 보이는 복도는 서로 비슷해서 헷갈릴 수 있습니다. 표지판을 찍도록 안내합니다.
- 공개 서비스로 운영하려면 역 운영사(코레일, 서울교통공사, 공항철도)에 촬영 및 이용 허가를 확인하세요.
- 다음 단계 아이디어: COLMAP으로 3D 지도 복원, 화살표 AR 안내, 여러 역 지원(`?station=이름`).
